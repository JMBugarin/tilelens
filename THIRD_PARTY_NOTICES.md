## Notes

- **Qt / PySide6 (LGPL-3.0).** TileLens uses PySide6 as an unmodified, dynamically loaded
  library. If you redistribute a packaged build, the LGPL requires that users can replace the
  Qt and PySide6 libraries and that the license text and source offer for Qt are passed on. The
  source is available from the Qt Project.
- **Fonts.** The synthetic renderer draws text with the fonts compiled into OpenCV
  (`cv2.FontFace`). No font files are included in this repository.
- **Word lists.** No word list from any game is included. `profiles/demo_words.txt` was written
  by hand for this project and is covered by the project's MIT license. Benchmarks can read the
  operating system's `/usr/share/dict/words` at run time; that file is not copied into the
  repository.
- **Game data.** No game's board layout, tile values, artwork or screenshots are included. The
  demo profiles and every image in this repository are fictional and were generated by
  TileLens itself.
